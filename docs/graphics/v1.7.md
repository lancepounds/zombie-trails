# v1.7 graphics — September 21, 2026

The update preserves the 320×160 canvas, monochrome palettes, numbered menus,
untimed encounters, route, event outcomes, and existing save format.
The built `index.html` contains all of the art code; preview images are for
documentation and are not downloaded by the game.

## Visual changes

- The shared station wagon has wood paneling, chrome trim, wheel arches,
  rotating hubs, roof luggage, and a driver silhouette. It is drawn larger
  during travel and in repair close-ups. Low body condition adds visible damage;
  the existing engine-trouble smoke remains.
- Shared survivor and zombie silhouettes have clearer heads, clothing, packs,
  limbs, and varied gait. Close-up travelers can stand, kneel to repair, sit,
  or hold a drink. Camp and drink-stop travelers follow the living party count.
- Regional scenery uses faceted mountain ridges, pine silhouettes, fields,
  grain silos, barns, desert mesas, town water towers, clouds, and utility wires.
  Trees, mountains, and clouds are cached per palette and geometry; they never
  use the journey RNG.
- The title and camp have a crescent night sky. Camp adds seated travelers,
  cups, tent shading, lantern, woodpile, and equipment. The existing smoke,
  shelter, kettle, and cloth animation remains.
- Repair close-ups show the wheel, jack, toolbox, working traveler, or open
  hood. The sickbed becomes a cot under a tarp, with a blanket, medical box,
  water bottle, and an attendant when another survivor is available.
- Five dedicated scene keys connect the summer events to their own pictures:
  `summer_flat`, `cold_drinks`, `ice_freezer`, `beer_tent`, and `sprinkler`.
  The cold-drink stand has a striped awning, timber counter, bottles, propane
  refrigerator, seated travelers, and a parked wagon. The beer tent includes
  pennants, fencing, and the dead. The sprinkler animates its spray and walkers.
- Primitive sizes snap to whole pixels. Dither sheets use nearest-neighbor
  image copies rather than filtered CanvasPattern sampling, preserving exact
  ink/paper pixels in the new illustrations. Existing optional scanlines can
  still soften alternate rows when enabled.

## Verification

`node build.js` and `npm run test:quick` passed: party, map, story/built-script,
regional content, Midwest content, audio, and **480 simulated campaigns with
zero crashes**. No gameplay rules or choice consequences changed. The existing
content suites resolved 27,680 regional and 9,024 Midwest choice outcomes.

`node test-render.js --previews docs/previews` passed **9,300 native renders
across 108 scene keys**. The checks cover:

- Both themes, all weather types, and representative mountain/plains states.
- One/five-person parties throughout, plus every party size on the new scenes.
- Driving, walking, poor vehicle condition, and breakdowns.
- Identical output with motion disabled at different times and distances.
- Visible prop animation, one-time arrivals, and a wagon that stays still
  after parking.
- Exact ink/paper pixels in the new illustrations at native resolution.
- No scene exceptions, game-state changes, or RNG consumption while drawing.

All six overview scenes were visually inspected in both palettes. The new
sprinkler, hood repair, and sickbed were also inspected in native renders during
development. The game interface layout was not changed. Browser interactions
and physical mobile-device rendering were not retested in this workspace.

A local warm-cache benchmark averaged approximately 3.4 ms per travel frame,
2.8 ms for the summer flat, 3.4 ms for the drink stand, and 4.4 ms for camp.
These are native Canvas measurements on the development machine, not browser
or mobile frame-rate guarantees.

## Reproducing the graphics checks

The game, build, and ordinary test suite need no npm dependencies. The separate
graphics check uses optional development package `@napi-rs/canvas`:

```bash
npm install --no-save --package-lock=false @napi-rs/canvas
node test-render.js --previews docs/previews
```

`npm run test:graphics` runs the same checks without regenerating images.
The harness catches scene errors that the production renderer normally
contains so a damaged illustration cannot interrupt the game.
